¿Por qué Windows muestra advertencia entonces?
Windows SmartScreen muestra ese aviso en TODOS los programas nuevos descargados de internet que no tienen un certificado digital pago ($300-500 USD/año). Es una protección genérica, no significa que el archivo tenga virus.

⚡ Soluciones rápidas

• ¿Windows bloquea el .exe? — Click en "Más información" → "Ejecutar de todas formas"
• ¿No carga/abre? — Ejecutá como Administrador (click derecho → Ejecutar como administrador)
• ¿Error de conexión? — Verificá tu internet. Algunas apps necesitan conexión (API de TMDB, YouTube, etc.)
• ¿Pantalla en blanco? — Cerrá y volvé a abrir. Si persiste, reportalo
• ¿SmartScreen insiste? — Descomprimí el ZIP en una carpeta, no ejecutes desde el navegador

🛡️ ¿Por qué Windows muestra una advertencia?
Tu seguridad es importante. Esto es exactamente lo que pasa y por qué estas apps son seguras.
🔒

Windows SmartScreen

Windows SmartScreen muestra una advertencia en TODO programa nuevo sin firma digital. No significa que tenga virus. Es una protección genérica para archivos descargados de internet. Para abrirlo: click en "Más información" → "Ejecutar de todas formas".

🔐

¿Por qué no está firmado?

Los certificados de firma de código (Code Signing) cuestan $300-500 USD por año. Este es software gratuito y libre. La firma digital NO garantiza que un programa sea seguro — solo identifica al editor.

✅

¿Cómo verificarlo?

1) Subí el .exe a VirusTotal.com para escanearlo con 70+ antivirus.
2) Verificá el hash SHA-256 de cada descarga.
3) El código fuente está disponible en GitHub.

🧪

VirusTotal: Falsos Positivos

70+ antivirus dicen LIMPIO. Solo 3-5 motores con IA/heurística marcan falso positivo.

• Microsoft: Wacatac.B!ml → El !ml significa Machine Learning adivinando
• CrowdStrike: 90% confidence → "No estamos seguros"
• Bkav: W32.Malware → Aplica firmas de Windows a archivos que no son de Windows
Kaspersky, ESET, Bitdefender, Avast, Norton, McAfee, Avira y 60+ más: LIMPIO ✅

⚠ Aviso Importante de Seguridad

WebSecurity Scanner Pro realiza peticiones HTTP reales a la URL de destino. Solo escaneá sitios web de tu propiedad o con autorización explícita.
