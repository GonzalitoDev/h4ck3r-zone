Nexus Tools, creado por GonzalitoDev, es un proyecto de software libre y gratuito enfocado en el desarrollo de aplicaciones de escritorio profesionales para Windows. Sin anuncios, sin trackers y con código 100% transparente disponible en GitHub.

El ecosistema Nexus abarca más de 12 aplicaciones en múltiples categorías:

Ciberseguridad y escaneo — WebSecurity Scanner Pro (23 módulos de escaneo de vulnerabilidades web con peticiones HTTP reales), CyberShield (escáner de malware con 8 módulos), NetGuard (escáner de red WiFi/ARP), Nexus VPN Pro (túnel encriptado AES-256 con kill switch).
Utilidades del sistema — PC Cleaner Premium (limpiador con modos estándar, profundo y ultra), Nexus Dashboard (compañero de escritorio cyberpunk con monitor de sistema en vivo y 4 temas), Nexus VPS Manager (panel de control para servidores vía SSH), Nexus Data Scraper (extracción de datos web).
Entretenimiento y media — Nexus Stream (100+ películas gratis de dominio público con reproducción directa), Nexus Movies (explorador de películas con API de TMDB, trailers, favoritos).
Apps móviles — CyberGuard para Android (herramientas de seguridad 100% offline: AES, TOTP, hash, generador de contraseñas), Nexus Mobile Toolkit (12 herramientas PWA/APK).
Herramientas de desarrollo — BetaTester Pro (kit QA para reportes de bugs), Nexus Hub (instalador universal con auto-updater), Nexus Server Pro (servidor web + proxy auto-hosteado).
